# Portfolio Optimization in Tehran Stock Exchange (TSE) 📈

[cite_start]This repository presents a research model for clustering and optimizing investment portfolios in the Tehran Stock Exchange using advanced data mining algorithms[cite: 1, 15].

---

## 🇬🇧 English Description

### Abstract
[cite_start]The management of investment baskets and asset selection is a critical decision-making problem in the financial sector[cite: 11]. [cite_start]This research aims to support investors and managers by developing a portfolio that considers realistic investor risk-taking behavior[cite: 13, 14]. [cite_start]The model uses data from 66 companies listed on the Tehran Stock Exchange[cite: 15, 59].

### Methodology
[cite_start]The proposed model follows a multi-stage process[cite: 53]:
* [cite_start]**Data Preparation**: Normalization of 24-month historical data using variance functions[cite: 60, 61].
* [cite_start]**Feature Selection**: Five key indexes are used: Risk, Output (Return), Skewness, Liquidity, and Current Ratio[cite: 15, 75].
* [cite_start]**Hybrid Clustering**: A combined method using **Self-Organizing Maps (SOM)** and **K-means** to identify similar company behaviors[cite: 68, 127].
* [cite_start]**Optimization**: Implementation of Genetic Algorithms to select the superior stocks[cite: 175, 180].

### Key Findings
* [cite_start]The research identifies that **7 clusters** provide the most optimized grouping for these companies[cite: 118, 163].
* [cite_start]The combined SOM and K-means method showed lower error rates (SSE) and better Davis-Bouldin index values compared to using them individually[cite: 165, 167].
* [cite_start]The resulting portfolio outperformed the general market index, industry index, and the index of the 50 most active companies[cite: 15, 178].

## 🇩🇪 Deutsche Beschreibung

### Zusammenfassung
[cite_start]Das Management von Investmentkörben ist eines der zentralen Entscheidungsprobleme im Finanzbereich[cite: 11, 18]. [cite_start]Diese Forschung unterstützt Investoren bei der Erstellung optimierter Aktienportfolios unter Berücksichtigung des realen Risikoverhaltens[cite: 13, 14]. [cite_start]Das Modell analysiert 66 an der Teheraner Börse gelistete Unternehmen[cite: 15, 59].

### Methodik
[cite_start]Das vorgeschlagene Modell nutzt einen mehrstufigen Prozess[cite: 53]:
* [cite_start]**Datenaufbereitung**: Normalisierung historischer 24-Monats-Daten[cite: 60, 61].
* [cite_start]**Indikatoren**: Verwendung von fünf Indizes: Risiko, Rendite, Schiefe (Skewness), Liquidität und Current Ratio[cite: 15, 75].
* [cite_start]**Hybrides Clustering**: Eine Kombination aus **Self-Organizing Maps (SOM)** und **K-means** zur Identifizierung ähnlicher Unternehmensmerkmale[cite: 68, 127].
* [cite_start]**Optimierung**: Einsatz von genetischen Algorithmen zur Auswahl der besten Aktien[cite: 175, 180].

### Hauptergebnisse
* [cite_start]Die optimale Anzahl der Cluster wurde mit **7** identifiziert[cite: 118, 163].
* [cite_start]Die kombinierte SOM-K-Means-Methode erzielte eine höhere Genauigkeit und geringere Fehlerwerte (SSE) als herkömmliche Methoden[cite: 165, 167].
* [cite_start]Das optimierte Portfolio übertraf den allgemeinen Marktindex sowie den Index der 50 aktivsten Unternehmen[cite: 15, 178].
